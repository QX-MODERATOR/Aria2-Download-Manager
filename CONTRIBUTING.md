# Contributing

Thanks for your interest in improving Aria2 Download Manager.

## Getting Started

1. Fork the repo and create a feature branch.
2. Install dependencies listed in BUILD.md.
3. Run the app in development:

```bash
npm install
npm run tauri dev
```

## Development Guidelines

- Keep changes focused and easy to review.
- Run tests or build steps relevant to your change.
- Use clear commit messages.

## Pull Requests

- Describe what changed and why.
- Include screenshots for UI changes when possible.
- Confirm the app still builds for your target platform.
